# Changelog

## v2

- Adds the **Yeet mode** field-reading analogy: a free safety recognizing the tell in a trips formation and making a bounded judgment inside the system.
- Adds the **Robert Horry principle**: preparation first, hesitation last — execute the already-decided shot without confusing decisiveness for recklessness.
- Defines `yeet` as **minimum ceremony, maximum certainty** rather than "skip process."
- Adds contextual handling for short follow-ups such as "do it then."
- Makes explicit user destination override generic publishing defaults.
- Adds connector-only GitHub semantics and SHA-guarded write rules.
- Adds direct-to-default-branch rules without treating `yeet` as permission escalation.
- Adds scope locking, proportional validation, diff gating, hard-failure semantics, CI handling, and remote verification.
- Adds a transport matrix and a non-mutating local preflight helper.
